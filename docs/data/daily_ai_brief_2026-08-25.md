Visual CoT는 중간 추론 이미지를 생성해 시각적 예견 능력을 제공하지만, 추론 과정에서 상당한 오버헤드가 발생하는 단점이 있다. 특히 실시간성이 중요한 선제적 비디오 추론 작업에서 이러한 연산 비용 문제는 더욱 심각하다. IVT는 모델이 학습 단계에서 시각적으로 사고하는 법을 배우고, 실제 추론 시에는 직접 결과를 도출하도록 설계되었다. 이 프레임워크는 텍스트 예측과 시각적 추론 과정을 공동 최적화하는 사후 학습 방식을 채택했다. 이를 통해 모델은 중간 이미지를 명시적으로 생성하지 않고도 내부적으로 시각적 추론 능력을 유지한다. 결과적으로 IVT는 Visual CoT의 직관적 추론 능력은 보존하면서 추론 속도를 획기적으로 개선했다. 이는 비디오 분석 및 자율 주행 등 빠른 판단이 필요한 환경에서 매우 효율적이다. 본 연구는 시각적 사고 과정을 내재화함으로써 효율성과 정확성의 균형을 맞추는 새로운 방향을 제시한다. 향후 멀티모달 모델의 실시간 응용 분야 확대에 크게 기여할 것으로 기대된다. IVT는 복잡한 시각적 환경에서의 능동적 추론 성능을 한 단계 끌어올린 기술적 진보이다.
